# 외부에서 거울 만들기

Figma · Canva · Photoshop · 그림 앱 등 어디서 만들어도 됩니다.
**배경을 직접 지울 필요는 없습니다** — 꾸미러가 가져올 때 카메라 자리를 자동으로 비웁니다.

---

## 1. 작업 크기

| | |
|---|---|
| 비율 | **9 : 19.5** |
| 권장 크기 | **1080 × 2340 px** |
| 더 크게 작업할 때 | 2160 × 4680 px (비율만 같으면 앱이 고품질로 줄입니다) |

비율이 다르면 가져올 때 거절합니다. **늘려서 왜곡시키지 않습니다.**

## 2. 카메라가 보일 자리

작업 크기 1080 × 2340 기준으로 이 자리가 카메라가 보이는 곳입니다.

| | 값 |
|---|---|
| 왼쪽에서 | 108 px (10%) |
| 위에서 | 180 px (약 7.7%) |
| 너비 | 864 px (80%) |
| 높이 | 1940 px (약 82.9%) |

위와 아래 여백이 다릅니다(위 180, 아래 220). 가운데가 아니니 주의하세요.

```
┌─────────────────────┐
│                     │  ← 위 180px
│   ┌─────────────┐   │
│   │             │   │
│   │  #00FF00    │   │
│   │   카메라     │   │  ← 864 × 1940
│   │             │   │
│   └─────────────┘   │
│                     │  ← 아래 220px
└─────────────────────┘
   ↑ 108px      108px ↑
```

## 3. 카메라 자리를 초록색으로 채우기

카메라가 보일 부분을 **`#00FF00`** 순수 초록색으로 채워 주세요.

```
#00FF00     RGB(0, 255, 0)
```

꾸미러가 가져올 때 **그 자리만** 투명하게 비웁니다.

> **초록색 장식을 써도 됩니다.**
> 카메라 자리 **바깥**의 초록색은 그대로 남습니다.
> 초록 꽃, 초록 글씨, 초록 리본 모두 안전합니다.

### 이미 투명하게 만들었다면

카메라 자리를 이미 투명(알파 0)하게 비워 두었다면 초록색을 칠하지 않아도 됩니다.
앱에서 내보낸 **작업 가이드 PNG** 위에 그렸다면 이 경우입니다.

## 4. 저장

| 형식 | |
|---|---|
| **PNG** | 권장. 색이 정확히 유지되고 투명도 지원 |
| JPEG | 가능. 압축 때문에 초록색이 조금 흔들릴 수 있어 약간의 오차는 감안합니다 |
| HEIC | 가능 |

## 5. 가져오기

```
내 거울 → 거울 만들기 → 외부에서 만들기 → 이미지 선택
```

## 문제가 생기면

**"카메라 자리를 찾지 못했어요"**
카메라 부분이 `#00FF00`으로 채워졌는지 확인하세요.
비슷한 초록(예: `#7CFF7C`)은 인식하지 않습니다 — 연두색 장식과 구분하기 위해서입니다.
자리의 대부분이 채워져 있어야 합니다.

**"작업 가이드와 비율이 달라요"**
9 : 19.5로 다시 내보내세요. 1080 × 2340이 가장 정확합니다.

**"거울 테두리가 없어요"**
카메라 자리 바깥에 그림이 거의 없습니다. 위치가 어긋났을 수 있으니 2번 항목의 좌표를 확인하세요.

**초록 장식이 사라졌어요**
카메라 자리 **안쪽**에 있던 초록색입니다. 그 자리는 카메라가 보여야 하므로 비워집니다.
장식은 자리 바깥으로 옮겨 주세요.
