# MIRROR Creator Template Guide v0.1

## 1. 목적

외부 툴(Figma, Procreate, Photoshop 등)에서 제작한 거울 프레임 디자인을
MIRROR 앱에 안정적으로 가져오기 위한 기본 제작 규격을 정의한다.

핵심 원칙은 다음과 같다.

- 상·하·좌·우 4장의 이미지를 각각 받지 않는다.
- 하나의 전체 프레임 마스터 이미지를 업로드한다.
- 앱 내부에서 상·하·좌·우 영역을 계산해 렌더링한다.
- 모서리 연결은 항상 하나의 원본 이미지 기준으로 유지한다.

## 2. 기본 업로드 포맷

### Master Frame

- 크기: 1080 × 2340 px
- 비율: 9 : 19.5
- 포맷: PNG
- 배경: 투명
- 색공간: sRGB 권장

중앙 거울 영역은 투명하게 유지하고,
장식은 외곽 프레임 영역을 중심으로 배치한다.

## 3. 프레임 영역

### MVP 규격 (현재 모든 거울이 동일)

- Canvas: 1080 × 2340 (9 : 19.5)
- 배경(Background) Layer의 중앙 Camera Area는 투명
- 프레임 두께는 아래 값으로 **고정**한다

| 면 | px | normalized |
|---|---|---|
| Left | 108 | 0.10 |
| Right | 108 | 0.10 |
| Top | 180 | 약 0.0769 |
| Bottom | 220 | 약 0.0940 |

중앙 Camera Area: 864 × 1940 (안쪽 네 모서리는 Master 기준 30px 라운드)

기본 거울 / 상점 템플릿 / 사용자 제작 거울 모두 같은 두께를 쓴다.
사용자가 프레임 두께를 바꾸는 기능은 제공하지 않는다.

의도:

- 좌우는 얇게 — 얼굴 시야를 최대한 확보한다
- 상·하는 조금 더 넓게 — 그림 / 텍스트 / 스티커를 넣을 공간을 둔다
- 아래를 위보다 조금 더 두껍게 — 세로 거울로서 무게중심을 잡는다

### 두 개의 Layer (중요)

**Background / Frame Base Layer**

- Camera Area는 반드시 투명
- 실제 거울에서 그 아래 카메라 영상이 그대로 비친다

**Decoration Layer** (그림 / 스티커 / 사진 / 향후 텍스트)

- **1080 × 2340 전체**를 쓸 수 있다
- Camera Area 위에도 올릴 수 있다 — 얼굴 위 콧수염 / 볼터치 / 머리 위 왕관이 가능하다
- 프레임과 Camera Area의 경계를 가로질러도 잘리지 않는다

즉 "Camera Area = 장식 금지 구역"이 아니다.
배경만 비우고, 장식은 캔버스 전체를 자유롭게 쓴다.

### 상점 템플릿의 차별점

프레임을 더 두껍게 만들어서가 아니라,
**같은 프레임 공간 안의 그림 / 낙서 / 스티커 밀도**로 차별화한다.

### 내부 모델 참고

앱 내부에는 `MirrorFrameInsets(top / right / bottom / left)`가 남아 있고
Canvas engine은 이 값을 읽어 렌더링한다.
향후 확장을 위한 구조일 뿐, 현재 제품에서는 위 고정값 하나만 사용한다.

과거 가이드의 216 px (Canvas Width의 20%)는 초기 reference였고
현재 규격이 아니다.

## 4. 제작 구조

권장 마스터 구조:

┌─────────────────────────────┐
│            TOP              │
│                             │
├─────┐                 ┌─────┤
│     │                 │     │
│LEFT │   MIRROR AREA   │RIGHT│
│     │  TRANSPARENT    │     │
│     │                 │     │
├─────┘                 └─────┤
│           BOTTOM            │
│                             │
└─────────────────────────────┘

전체 파일은 하나의 PNG다.

앱 내부에서 필요한 경우 TOP / BOTTOM / LEFT / RIGHT 영역을
sourceRect 기준으로 잘라서 사용한다.

원본 파일 자체를 4개의 별도 자산으로 분리하는 것은 기본 정책이 아니다.

## 5. 모서리 연속성

TOP / LEFT / RIGHT / BOTTOM은 시각적으로 하나의 프레임이어야 한다.

따라서 네 모서리 장식이 자연스럽게 연결되도록 하나의 캔버스에서 제작한다.

리본, 선, 패턴, 장식 등이 모서리를 넘어가는 디자인도 허용한다.

## 6. 기기별 대응 원칙

iPhone 기종마다 화면 비율이 다르기 때문에
1080 × 2340 이미지를 모든 화면에 X/Y 독립 Stretch하지 않는다.

금지:

- 가로만 늘이기
- 세로만 늘이기
- 원, 리본, 캐릭터 등이 찌그러지는 비균등 스케일

권장:

- Uniform Scale
- Crop
- Extend
- Safe Frame 기준 보정

외부 이미지 템플릿은 원본 비율을 유지하는 것을 우선한다.

## 7. 앱 내부 제작 템플릿과의 차이

### Native Template

앱 내부 Editor에서 만든 템플릿.

위치와 크기를 0~1 범위 normalized coordinate로 저장한다.

예:

x = 0.14
y = 0.82
width = 0.18

장점:

- 다양한 iPhone 화면 대응
- 수정 가능
- Remix 가능
- 객체 단위 편집 가능

### Image Template

외부 제작 도구에서 만든 완성형 프레임.

기본 입력:

- 1080 × 2340
- 투명 PNG 1장

앱에서 화면 비율에 맞게 매핑한다.

## 8. 업로드 UX

MVP의 Creator Upload는 단순하게 유지한다.

1. 전체 프레임 PNG 선택
2. 규격 검사
3. 전체 미리보기
4. 여러 iPhone 비율 미리보기
5. 필요 시 위치/Scale 보정
6. 저장 또는 Store 등록

## 9. 업로드 검증

업로드 시 최소 검증 항목:

- PNG 여부
- 1080 × 2340 권장 규격 여부
- 투명 영역 존재 여부
- 파일 용량
- 중앙 거울 영역 가림 정도
- 중요한 장식의 Safe Frame 이탈 여부

권장 규격과 다를 경우 자동 변환 또는 사용자 보정을 제공할 수 있다.

## 10. Compact / Legacy 대응

기본 Master는 9:19.5 하나만 필수로 한다.

향후 필요 시 추가 변형을 지원할 수 있다.

Optional Compact Master:

- 1080 × 1920
- 9 : 16

초기 MVP에서는 필수가 아니다.

## 11. MVP 결정사항

초기 버전에서는:

- 전체 프레임 PNG 1장 업로드만 지원
- 1080 × 2340 / 9:19.5를 기준 Master로 사용
- 중앙 거울 영역은 투명
- 프레임 두께는 모든 거울이 동일 (좌우 0.10 / 상하 약 0.0769)
- 앱 내부에서 상·하·좌·우 영역 계산
- 모서리 연속성 유지
- 비균등 Stretch 금지
- 기기별 Uniform Scale + Crop/Extend
- 앱 내부 제작물은 normalized coordinate 사용

향후 고급 크리에이터 기능으로:

- 4면 개별 업로드
- Compact/Legacy 전용 Master
- 반복 패턴형 Edge Asset
- 기기군별 커스텀 보정

등을 검토한다.

## 12. 사용자 External Artwork Workflow (구현 완료)

Creator 업로드와 별개로, **일반 사용자도 같은 규격으로 자기 거울을 만든다.**

```
꾸미러 [내 거울 → + 거울 만들기 → 외부에서 만들기]
  → 작업 가이드 저장 (1080 × 2340 투명 PNG)
  → 그림 앱(Procreate / ibisPaint / Photoshop 등)에서 가이드를 참고 레이어로 깔고 작업
  → 가이드 레이어 숨기고 투명 PNG로 내보내기
  → 꾸미러로 가져오기 (사진 / 파일)
  → 미리보기에서 정렬 확인 → "이 디자인 사용"
  → 전체 Canvas 고정 Artwork Layer로 Editor에 깔린다
```

작업 가이드에 들어 있는 것

- 1080 × 2340 전체 외곽선
- 중앙 Camera Area 둥근 모서리 dashed line (앱과 같은 geometry: 108 / 108 / 180 / 220, radius 30)
- 그 외에는 전부 투명 — 밑에 깔고 그리기 위한 참고선이다

지켜야 하는 것

- 크기: 정확히 1080 × 2340, 또는 같은 9 : 19.5 비율의 더 큰 이미지(자동 축소)
- 포맷: 투명도를 지원하는 PNG
- 비율이 다르면 앱이 왜곡시키지 않고 되묻는다

**Camera Area는 가져올 때 지워진다.**
점선 안쪽은 실제 거울에서 카메라가 보이는 곳이다.
외부 디자인은 **프레임용 overlay**라서, 점선 안쪽에 그린 부분은 가져오는 과정에서 alpha 0이 된다.
그러니 프레임 영역을 꾸미면 된다. 배경을 꽉 채워 내보내도 막히지 않고 프레임만 남는다.
카메라 영역 위의 장식(콧수염 / 왕관 / 하트)은 앱 안의 그리기 / 스티커 / 텍스트로 얹는다.

앱 안에서의 성질

- 위치 / 크기 / 회전이 없다. 언제나 Master Canvas 전체에 정확히 맞는다.
- 카메라 영역은 비어 있다 — 실제 거울에서 얼굴을 절대 가리지 않는다.
- 캔버스를 눌러 고르지 않는다 — `레이어` 목록에서 고른다.
- 그 위에 꾸미러의 그리기 / 스티커 / 사진 스티커 / 텍스트를 계속 얹을 수 있다.

## 13. 핵심 원칙 요약

Creator에게는 한 장.

앱 내부에서는 네 면.

사용자에게는 하나의 거울.

이 구조를 MIRROR 템플릿 시스템의 기본 원칙으로 한다.
